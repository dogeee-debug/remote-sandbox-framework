## Launch Post Blurb

Shipping `remote-sandbox-framework` as a minimal autoresearch multi-agent kernel.

Instead of giving agents unrestricted tool autonomy, it uses deterministic boards, artifact handoffs, append-only event logs, and bounded shell execution.

It runs locally without a model, but can also plug into any OpenAI-compatible endpoint for planning and synthesis.
